# @arza/config

Configuración compartida de las herramientas de calidad.

- `eslint.js`: reglas de código limpio del capítulo 11.2 del manual. La usa `eslint.config.js` en la raíz.
- `test/`: pruebas que demuestran que los controles funcionan: mensajes de commit, secretos,
  fronteras entre módulos y reglas del analizador.

La configuración de TypeScript compartida está en `tsconfig.base.json` en la raíz del repositorio.
