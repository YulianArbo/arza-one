# B06 — Entorno local completo

- Fase: F1 Cimientos
- Módulo: Infraestructura
- Depende de: B02 · B03
- Bloque crítico (requiere revisión externa): No

## Lectura obligatoria del manual (docs/manual)
- capítulos 10, 22
- Capítulos 12 (base de datos), 13 (backend), 14 (API), 15 (seguridad) y 16 (interfaz) en lo que aplique
- Capítulo 21: definición de terminado

## Entregables
- Docker Compose local con PostgreSQL, Valkey, Garage, Gotenberg, ClamAV y Mailpit
- Un solo comando para levantar todo y otro para reiniciar los datos
- Worker con BullMQ y un trabajo de ejemplo

## Criterios de aceptación
- [ ] Un equipo nuevo levanta el proyecto siguiendo solo el README
- [ ] El trabajo de ejemplo se ejecuta y se reintenta al fallar
- [ ] `pnpm check` en verde
- [ ] Pruebas de permiso denegado, aislamiento entre empresas y auditoría
- [ ] Documentación y cierre del bloque escritos
