# B02 — Esqueleto de la API

- Fase: F1 Cimientos
- Módulo: Plataforma
- Depende de: B01
- Bloque crítico (requiere revisión externa): No

## Lectura obligatoria del manual (docs/manual)
- capítulos 8, 11, 13
- Capítulos 12 (base de datos), 13 (backend), 14 (API), 15 (seguridad) y 16 (interfaz) en lo que aplique
- Capítulo 21: definición de terminado

## Entregables
- NestJS con configuración validada, registros Pino, identificador de correlación, formato único de error, Helmet, límite de peticiones, rutas /health y /version
- OpenAPI generado desde esquemas Zod
- Pruebas unitarias e integración de la cadena de petición

## Criterios de aceptación
- [ ] La API no arranca si falta una variable de entorno
- [ ] Un error inesperado devuelve el formato del numeral 14.2 sin traza
- [ ] /health informa el estado de base de datos, colas y archivos
- [ ] `pnpm check` en verde
- [ ] Pruebas de permiso denegado, aislamiento entre empresas y auditoría
- [ ] Documentación y cierre del bloque escritos
