## Entregables
- Tablas de roles, permisos y asignaciones; catálogo de permisos del anexo G como dato semilla
- Guarda de autorización con CASL (RBAC y ABAC) y decorador por punto de la API; respuesta filtrada por rol
- Pantallas de usuarios, roles y delegaciones; informe de revisión de accesos

## Criterios de aceptación
- [ ] Cada punto de la API declara su permiso; una prueba falla si alguno no lo hace
- [ ] Nadie puede asignarse permisos a sí mismo
- [ ] La interfaz oculta lo que el usuario no puede hacer y la API lo deniega igual
- [ ] `pnpm check` en verde
- [ ] Pruebas de permiso denegado, aislamiento entre empresas y auditoría
- [ ] Documentación y cierre del bloque escritos
