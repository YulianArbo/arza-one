# Guion de aceptación — M14 Calidad y mejora continua

Prueba de aceptación de usuario del numeral 21.1: el líder del proceso comprueba que el módulo sirve
al proceso. Se hace en el **servidor de pruebas**, con datos **ficticios**, nunca en producción.
Los pasos siguen los criterios de la ficha 17.15 del Manual Maestro.

| Campo                 | Valor                               |
| --------------------- | ----------------------------------- |
| Aprueba               | Coordinador de Calidad e Innovación |
| Cuenta para la prueba | CALIDAD                             |
| Fecha de la prueba    | dd/mm/aaaa                          |
| Versión probada       | vX.Y.Z                              |
| Probó                 |                                     |

## Antes de empezar

- Cuentas de prueba con los roles indicados y segundo factor activo.
- Una queja procedente de prueba (guion M08).

## Pasos

| N.º | Paso                                                                           | Resultado esperado                               | ¿Cumple? (Sí/No) | Observación |
| --- | ------------------------------------------------------------------------------ | ------------------------------------------------ | ---------------- | ----------- |
| 1   | Abra la no conformidad que creó la queja.                                      | Está enlazada a su origen.                       |                  |             |
| 2   | Cierre una acción y verifique su eficacia con la misma persona que la ejecutó. | La plataforma no lo permite.                     |                  |             |
| 3   | Asigne a un auditor su propio proceso.                                         | La plataforma no lo permite.                     |                  |             |
| 4   | Compare la bitácora de acciones con RE-SGC-002.                                | Coinciden.                                       |                  |             |
| 5   | Abra la matriz de indicadores.                                                 | Muestra meta, resultado y tendencia por proceso. |                  |             |

## Resultado

- [ ] **Aprobado:** todos los pasos cumplen.

- [ ] **No aprobado:** se repite el guion cuando se corrija.
