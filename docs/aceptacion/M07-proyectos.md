# Guion de aceptación — M07 Proyectos y desarrollo de software

Prueba de aceptación de usuario del numeral 21.1: el líder del proceso comprueba que el módulo sirve
al proceso. Se hace en el **servidor de pruebas**, con datos **ficticios**, nunca en producción.
Los pasos siguen los criterios de la ficha 17.8 del Manual Maestro.

| Campo                 | Valor                              |
| --------------------- | ---------------------------------- |
| Aprueba               | Gerente de Desarrollo y Tecnología |
| Cuenta para la prueba | LIDER_TECNICO                      |
| Fecha de la prueba    | dd/mm/aaaa                         |
| Versión probada       | vX.Y.Z                             |
| Probó                 |                                    |

## Antes de empezar

- Cuentas de prueba con los roles indicados y segundo factor activo.
- Un contrato firmado de prueba.

## Pasos

| N.º | Paso                                                              | Resultado esperado                                          | ¿Cumple? (Sí/No) | Observación |
| --- | ----------------------------------------------------------------- | ----------------------------------------------------------- | ---------------- | ----------- |
| 1   | Cree el proyecto desde el contrato.                               | El proyecto toma cliente, hitos y presupuesto de horas.     |                  |             |
| 2   | Agregue una historia sin criterios de aceptación a una iteración. | La plataforma no lo permite.                                |                  |             |
| 3   | Mueva un ítem en el tablero desde otra sesión.                    | El cambio se ve en tiempo real en la otra sesión.           |                  |             |
| 4   | Registre horas con más de siete días de atraso.                   | La plataforma no lo permite.                                |                  |             |
| 5   | Entregue un entregable y acéptelo desde el portal del cliente.    | Se genera el acta firmada y se propone la factura del hito. |                  |             |
| 6   | Retire a un miembro del proyecto.                                 | Pierde el acceso de inmediato.                              |                  |             |

## Resultado

- [ ] **Aprobado:** todos los pasos cumplen.
- [ ] **Aprobado con observaciones:** no impiden usar el módulo y tienen fecha de arreglo.
- [ ] **No aprobado:** se repite el guion cuando se corrija.
