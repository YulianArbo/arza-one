# Guion de aceptación — M13 Seguridad y salud en el trabajo

Prueba de aceptación de usuario del numeral 21.1: el líder del proceso comprueba que el módulo sirve
al proceso. Se hace en el **servidor de pruebas**, con datos **ficticios**, nunca en producción.
Los pasos siguen los criterios de la ficha 17.14 del Manual Maestro.

| Campo                 | Valor                                    |
| --------------------- | ---------------------------------------- |
| Aprueba               | Líder de Seguridad y Salud en el Trabajo |
| Cuenta para la prueba | SST                                      |
| Fecha de la prueba    | dd/mm/aaaa                               |
| Versión probada       | vX.Y.Z                                   |
| Probó                 |                                          |

## Antes de empezar

- Cuentas de prueba con los roles indicados y segundo factor activo.
- Un celular con la plataforma abierta.

## Pasos

| N.º | Paso                                                                     | Resultado esperado                                                   | ¿Cumple? (Sí/No) | Observación |
| --- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | ---------------- | ----------- |
| 1   | Desde el celular, como colaborador, reporte una condición insegura.      | Lo logra en menos de un minuto.                                      |                  |             |
| 2   | Registre un accidente de trabajo de prueba.                              | Alerta el plazo de dos días hábiles para reportarlo a la ARL.        |                  |             |
| 3   | Registre un examen médico.                                               | Solo admite concepto de aptitud y restricciones, nunca diagnósticos. |                  |             |
| 4   | Haga la autoevaluación de estándares mínimos y compárela con RE-SST-003. | El puntaje coincide.                                                 |                  |             |
| 5   | Revise el plan anual.                                                    | Muestra el porcentaje de cumplimiento con sus evidencias.            |                  |             |

## Resultado

- [ ] **Aprobado:** todos los pasos cumplen.
- [ ] **Aprobado con observaciones:** no impiden usar el módulo y tienen fecha de arreglo.
- [ ] **No aprobado:** se repite el guion cuando se corrija.
