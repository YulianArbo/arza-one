# Guion de aceptación — M04 Flujos, tareas y notificaciones

Prueba de aceptación de usuario del numeral 21.1: el líder del proceso comprueba que el módulo sirve
al proceso. Se hace en el **servidor de pruebas**, con datos **ficticios**, nunca en producción.
Los pasos siguen los criterios de la ficha 17.5 del Manual Maestro.

| Campo                 | Valor                               |
| --------------------- | ----------------------------------- |
| Aprueba               | Coordinador de Calidad e Innovación |
| Cuenta para la prueba | COLABORADOR y su jefe               |
| Fecha de la prueba    | dd/mm/aaaa                          |
| Versión probada       | vX.Y.Z                              |
| Probó                 |                                     |

## Antes de empezar

- Cuentas de prueba con los roles indicados y segundo factor activo.
- Una solicitud que genere una tarea (por ejemplo, una solicitud de vacaciones).

## Pasos

| N.º | Paso                                                      | Resultado esperado                                             | ¿Cumple? (Sí/No) | Observación |
| --- | --------------------------------------------------------- | -------------------------------------------------------------- | ---------------- | ----------- |
| 1   | Abra Mis tareas.                                          | Aparecen las tareas pendientes con su vencimiento y prioridad. |                  |             |
| 2   | Deje vencer una tarea de prueba.                          | Escala al jefe inmediato.                                      |                  |             |
| 3   | Revise el historial del registro.                         | Muestra actor, fecha, decisión y comentario de cada paso.      |                  |             |
| 4   | Genere un aviso no urgente un sábado para un colaborador. | Se entrega el lunes a las 8:00 a. m.                           |                  |             |
| 5   | En su perfil cambie las preferencias de avisos.           | Los avisos siguientes respetan la preferencia.                 |                  |             |
| 6   | Comente un registro mencionando a otra persona.           | La persona mencionada recibe el aviso.                         |                  |             |

## Resultado

- [ ] **Aprobado:** todos los pasos cumplen.
- [ ] **Aprobado con observaciones:** no impiden usar el módulo y tienen fecha de arreglo.
- [ ] **No aprobado:** se repite el guion cuando se corrija.
