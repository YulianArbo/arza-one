# M08 Servicio al cliente

**Para qué sirve.** Atiende solicitudes, incidentes y PQRSF a tiempo y mide la satisfacción.

**Dónde está.** Servicio › Tiquetes, PQRSF y Base de conocimiento.

**Quién lo usa.** Servicio al cliente; el líder aprueba las respuestas de PQRSF.

## Tareas frecuentes

### Atender un tiquete

1. Abra Servicio › Tiquetes y tome el tiquete.
2. Si espera al cliente, póngalo «en espera»: el reloj se detiene.
3. Resuélvalo: el cliente recibe la encuesta.

### Responder una PQRSF

1. Clasifíquela en Servicio › PQRSF.
2. Redacte la respuesta; el líder del proceso la aprueba antes de enviarla.

## Bueno saber

- Toda PQRSF tiene radicado y fecha límite.
- Una queja procedente abre una no conformidad en Calidad.
- Los reclamos de datos personales pasan a Privacidad.

Si no ve una opción, su rol no la tiene: pida el acceso a su jefe. Vea también
[Primeros pasos](00-primeros-pasos.md).
