# M17 Sitio web

**Para qué sirve.** El sitio público, sus formularios, los textos legales y las cookies.

**Dónde está.** Sitio web › Páginas y Formularios recibidos.

**Quién lo usa.** Dirección y Oficial de datos.

## Tareas frecuentes

### Publicar un texto legal

1. Redacte la versión, otra persona la aprueba con el concepto jurídico adjunto y se publica.

### Revisar formularios recibidos

1. Sitio web › Formularios recibidos muestra lo que llegó y a dónde pasó.

## Bueno saber

- Las cookies no necesarias no se instalan antes de aceptar.
- Publicar términos nuevos obliga a aceptarlos en el siguiente ingreso.

Si no ve una opción, su rol no la tiene: pida el acceso a su jefe. Vea también
