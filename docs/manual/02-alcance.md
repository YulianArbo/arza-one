# 2. Alcance

Este manual aplica a todo el ciclo de vida de ARZA ONE: diseño, construcción, pruebas, despliegue, operación, mantenimiento y evolución. Cubre el sitio web público, la aplicación interna para colaboradores, el portal de clientes, la interfaz de programación, la base de datos, el almacenamiento de archivos, el servidor y las integraciones con servicios externos.

La plataforma se construye primero para el uso interno de ARZA TECH S.A.S. y queda preparada, desde el modelo de datos, para atender en el futuro a otras empresas como servicio (multiempresa). La primera versión en producción comprende el núcleo transversal, la gestión documental, el ciclo comercial con contratos y firma electrónica, proyectos, servicio al cliente con PQRSF, el portal de clientes y el sitio público con sus textos legales. Los módulos de finanzas, compras, talento humano, seguridad y salud en el trabajo, mejora continua e indicadores se incorporan en las fases siguientes.

**Lo que la plataforma no reemplaza**

- La contabilidad oficial, la liquidación de nómina y la transmisión de factura y nómina electrónicas a la DIAN se realizan en el software contable habilitado que administra el Contador Público. ARZA ONE registra la operación (qué se factura, a quién, cuánto se debe, qué novedades hubo) y guarda el número y el soporte del documento fiscal; no genera el XML fiscal ni lo transmite.

- El criterio profesional del abogado, el contador y el responsable de seguridad y salud en el trabajo. La plataforma aplica controles y guarda evidencias, pero los textos legales y los módulos regulados se validan con el profesional competente antes de publicarse.

- Las herramientas con las que se escribe el software para los clientes (repositorios, editores, nube de cada proyecto). ARZA ONE gestiona el proyecto y enlaza esas herramientas; no las sustituye.
